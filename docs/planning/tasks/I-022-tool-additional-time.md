A one-use tool that adds time to the current round. Presupposes a timed mode, which does not exist - `Stage` has `threshold` and `moves` and no clock, and nothing in the engine is time-bounded. So this is really two ideas: a timed mode, and a tool for it. Worth keeping as a pair rather than promoting the tool alone. A timer would also be the first pressure in the game that punishes thinking, which is a different feel from the move budget and should be a deliberate choice rather than a side effect of wanting this tool.
