## Description

The game never tells anyone they finished it. Clearing the last stage offers the
endless fork, and declining it produces the same stage-clear panel with a replay
button that every other stage produces. There is no completion state, no
acknowledgement that the sequence is over, and nothing on the stage select that
distinguishes a finished game from a nearly finished one.

Someone can reach the end of the content without noticing that is what happened.
For a game short enough to finish in a sitting, the ending is a substantial part
of what it feels like to have played it.

## Acceptance criteria

<!-- AC:BEGIN -->
- [ ] #1 Clearing the final stage is acknowledged as finishing the game, not as
      clearing a stage
- [ ] #2 Completion is recorded and visible on return
- [ ] #3 The endless fork still works and does not pre-empt the ending
