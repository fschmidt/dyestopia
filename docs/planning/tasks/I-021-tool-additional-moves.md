A one-use tool that adds moves to the current round. The simplest possible tool - no board interaction, no targeting, just budget. `D-002`'s objection to tools does not bite here, because moves are not the broken resource; this adds to a budget that already works rather than papering over one that does not. The care needed is that every stage threshold is calibrated against its move count, so a tool that hands out moves is a direct multiplier on the win rate of whichever stages it is available in.
